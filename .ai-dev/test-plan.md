# 自媒体内容排版器测试方案

- 文档状态：待审批
- 测试基线：`npm test` 现有 14 项通过，`npm run lint` 通过，`npm run build` 通过
- 验收数据：12 篇固定文章，覆盖叙事、知识、商业案例、长文、列表、引用、图片、异常 Markdown

## 1. 测试原则

- 每项 P0 需求必须有自动化测试或明确的人工验收步骤。
- 布局判断同时使用数值边界检查和浏览器截图，不用“看起来正常”代替验收。
- AI 采用固定响应夹具完成确定性测试；真实模型只做发布前人工抽检。
- 不允许删除现有测试、降低断言、跳过失败测试或用裁切隐藏溢出。

## 2. 测试场景

### TEST-001 新建、保存和删除项目

- 需求：REQ-001、REQ-010
- 层级：组件测试、端到端测试
- 前置条件：浏览器本地数据为空。
- 步骤：新建项目，输入标题和正文，等待自动保存，刷新后重新打开，再执行删除和取消删除。
- 期望结果：项目可恢复；取消删除不改变数据；确认删除后项目和无引用素材被移除。
- 自动化：Vitest + fake IndexedDB；Playwright。

### TEST-002 项目空状态和存储不可用

- 需求：REQ-001、REQ-010、REQ-013
- 层级：组件测试
- 前置条件：无历史项目；分别模拟 IndexedDB 打开失败和写入失败。
- 步骤：打开应用并新建项目，触发保存。
- 期望结果：空状态提供新建入口；写入失败显示未保存状态；当前会话内容不丢失。
- 自动化：Vitest。

### TEST-003 Markdown 与普通文本结构识别

- 需求：REQ-002
- 层级：单元测试
- 前置条件：准备标题、段落、引用、列表、图片、重点和分页标记夹具。
- 步骤：分别解析 Markdown 和普通文本。
- 期望结果：块类型、顺序、原文位置和有效正文覆盖率符合夹具。
- 自动化：Vitest 参数化测试。

### TEST-004 异常内容清洗与降级

- 需求：REQ-002、REQ-013
- 层级：单元测试
- 前置条件：输入单独 `>`、空标题、残留 `font-weight`、损坏 Markdown 和超长单段。
- 步骤：执行标准化。
- 期望结果：空块和样式残留被过滤；有效文字不丢失；无法识别内容降级为普通段落。
- 自动化：Vitest。

### TEST-005 四种平台版本独立生成

- 需求：REQ-003、REQ-005、REQ-006、REQ-007
- 层级：单元测试、集成测试
- 前置条件：已解析一篇包含标题、正文、引用、列表和图片的文章。
- 步骤：依次生成公众号、小红书、抖音图文和抖音长文，再修改其中一个版本。
- 期望结果：四种版本结构完整；修改仅影响目标平台；源文章不变。
- 自动化：Vitest。

### TEST-006 重新生成、确认和锁定

- 需求：REQ-003、REQ-008
- 层级：组件测试
- 前置条件：平台版本含人工修改和一张锁定页面。
- 步骤：触发重新生成，先取消，再确认。
- 期望结果：取消后内容不变；确认后未锁定内容更新；锁定内容保留。
- 自动化：React 组件测试或 Playwright。

### TEST-007 AI 正常生成与结构校验

- 需求：REQ-004
- 层级：单元测试、契约测试
- 前置条件：模拟 OpenAI-compatible 服务返回合法结构。
- 步骤：生成四个平台的标题、摘要、重点、文案、标签和分组建议。
- 期望结果：输出通过校验并进入对应平台草稿；记录模型和源版本，不记录密钥。
- 自动化：Vitest + Mock Service Worker 或 fetch mock。

### TEST-008 AI 超时、限流、取消和非法返回

- 需求：REQ-004、REQ-013
- 层级：单元测试
- 前置条件：分别模拟超时、429、用户取消、非法 JSON 和缺少字段。
- 步骤：执行生成。
- 期望结果：不覆盖已有版本；停止自动重试；提供重试或基础版本；无未处理异常。
- 自动化：Vitest。

### TEST-009 AI 事实一致性验收

- 需求：REQ-004、REQ-014
- 层级：离线验收、人工复核
- 前置条件：12 篇固定文章及对应模型输出。
- 步骤：逐条比对输出中的数字、案例、引用和结论与源文。
- 期望结果：不存在源文无法支持的新增事实；不合格结果被拒绝，不进入发布状态。
- 自动化：结构和差异检查自动化；事实一致性由独立审查者复核。

### TEST-010 公众号直接编辑与富文本复制

- 期望结果：导出内容与修改后预览一致；无裸露 Markdown；内联样式保留。
