浏览器实拍位于本机 `artifacts/account-center/production/`。

## 隔离环境

隔离环境：Playwright Chromium，当前产品源码及 Next.js 生产构建，独立 PostgreSQL、Casdoor、账号中心进程和两名 `qa_formatter_*` 消费者。管理员通过隔离 Casdoor 的真实授权码登录并调用中心管理员接口，只使用少量测试会员和额度。故障注入、调整测试账号到期时间、修改孤立任务故障状态均只在隔离环境进行。

- 产品：`http://localhost:3347`；实际回调：`http://localhost:3347/auth/callback/wechat-article-formatter`。
- 隔离中心：`http://localhost:3348`；issuer：`http://localhost:3346`。隔离明文回环例外未用于正式 HTTPS 配置。

| 验收项 | 实际结果 |
| --- | --- |
| 登录、刷新、服务重启 | Chromium 经真实 Casdoor 页面登录，验证精确回调、PKCE S256、HttpOnly、SameSite；刷新打开原稿，重启产品进程后保持同一个账号和服务端会话。回调仅可使用一次。 |
| A/B 与旧库 | A 保存并刷新打开私稿；直接读 IndexedDB 核对正文和标题不以明文存储。切换到 B 后 A 稿不出现，B 不能使用 A 的页面绑定，A/B 权益各自查询；B 重放 A 的准确任务编号和请求体，仍无法读取 A 的排版结果或改变原任务。预置未关联旧库哨兵原样，未迁移。现有正式旧版部署及原浏览器库未写入。 |
| 会员、额度、过期 | 管理员经真实中心接口为 A 开通一天会员和一次智能排版额度；A 显示实发状态，B 为零。模拟 A 到期后仍能登录并读取私稿，服务端拒绝高级视觉分析。 |
| 真实生成、并发、响应丢失 | 三个并发请求（两次同编号、一次不同编号）争用一份额度，实际调用已配置模型并返回 AI 排版。中心确认已提交后断开响应，首次权威查询也返回 503；任务保留待恢复，按原编号重查后交付。中心只有一笔确认、余额和预占均为零；重复返回同一方案。 |
| 业务失败、取消与返还 | 关闭隔离模型触发实际排版失败，中心预占取消并恢复原余额。另用真实预占和确认构造确认后缺少可交付结果的故障；用户退出后从产品恢复端点核对并返还，反复恢复只有一条返还审计。无调度密钥的请求返回 404。 |
| 兑换和返回 | 产品申请真实导航上下文，从中心页面兑换一个测试码，重复提交返回原结果。通过中心的可信产品链接返回，查询后显示增加一次，没有依据 URL 本地加权益。 |
| 账号安全、取消、多标签与过期 | 中心已登录 A 时，B 从产品进入账号与安全会收到不同账号提示，未静默合并。过期上下文报错；取消回到未登录；旧标签登录尝试被新标签替换，重复回调被拒。 |
| 退出、封禁和产品边界 | 当前退出后中心会话仍有效、产品不能再调用受限接口。全部退出经中心确认后，中心和另一浏览器中的产品会话均在下一次查询中失效。封禁拒绝新任务，消费者不能访问管理 API，独立产品密钥跨产品请求返回 403。 |
| 客户端产物 | 隔离生产构建的客户端产物和浏览器账号响应中未出现产品密钥、OIDC secret、数据库连接或调度凭据。 |

定向检查：5 个现有测试文件共 31 项通过（浏览器旧库、服务端 AI 客户端、视觉接口）；改动范围 ESLint、TypeScript、Next.js 生产构建及差异空白检查通过。未执行全项目测试矩阵。隔离中心管理页面的前端包与本地管理代理存在路由差异，测试管理员通过该服务真实 OIDC 和受认证管理 API 操作；消费者产品和中心兑换页面使用实际浏览器点击。
